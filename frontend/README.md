# Frontend - سیستم انتخاب واحد

پروژه فرانت‌اند React با Vite برای پنل مدیریت دروس

## ویژگی‌ها

- ✅ صفحه لاگین مدیر با JWT Authentication
- ✅ داشبورد مدیریت دروس
- ✅ نمایش لیست تمام دروس در جدول
- ✅ افزودن درس جدید (مودال)
- ✅ ویرایش درس (مودال)
- ✅ حذف درس
- ✅ مدیریت خودکار توکن (ذخیره در localStorage)
- ✅ رفرش خودکار توکن در صورت انقضا
- ✅ هدایت خودکار به صفحه لاگین در صورت عدم احراز هویت
- ✅ طراحی زیبا با Tailwind CSS

## پیش‌نیازها

- Node.js (نسخه 16 یا بالاتر)
- npm یا yarn

## نصب و راه‌اندازی

1. نصب وابستگی‌ها:
```bash
cd frontend
npm install
```

2. اجرای پروژه:
```bash
npm run dev
```

پروژه روی `http://localhost:3000` اجرا می‌شود.

## ساخت برای Production

```bash
npm run build
```

فایل‌های آماده در پوشه `dist` قرار می‌گیرند.

## استفاده

### لاگین

1. به آدرس `http://localhost:3000/login` بروید
2. هر نام کاربری و رمز عبوری را وارد کنید (در حالت mock، همه چیز پذیرفته می‌شود)
3. پس از لاگین موفق، به داشبورد هدایت می‌شوید

### مدیریت دروس

- **مشاهده لیست**: تمام دروس در جدول نمایش داده می‌شوند
- **افزودن درس**: روی دکمه "افزودن درس جدید" کلیک کنید
- **ویرایش درس**: روی دکمه "ویرایش" در ردیف مربوطه کلیک کنید
- **حذف درس**: روی دکمه "حذف" در ردیف مربوطه کلیک کنید

## اتصال به بک‌اند

**نکته:** در حال حاضر پروژه از **mock data** استفاده می‌کند و به بک‌اند متصل نیست.

برای اتصال به بک‌اند:
1. فایل `src/services/courseService.js` را ویرایش کنید و به جای mock data از API واقعی استفاده کنید
2. فایل `src/api.js` را ویرایش کنید و توابع mock را با درخواست‌های واقعی جایگزین کنید
3. فایل `src/pages/Login.jsx` را ویرایش کنید و از `login` در `api.js` استفاده کنید

پس از اتصال:
- **Base URL**: `http://127.0.0.1:8000/api/`
- **Authentication**: JWT Token در localStorage ذخیره می‌شود
- **Auto Refresh**: در صورت انقضای توکن، به صورت خودکار رفرش می‌شود

## تکنولوژی‌ها

- **React 18**: کتابخانه UI
- **Vite**: Build tool و Dev Server
- **React Router**: مدیریت Routing
- **Axios**: HTTP Client
- **Tailwind CSS**: استایل‌دهی

## نکات مهم

- توکن‌ها در `localStorage` ذخیره می‌شوند
- در صورت انقضای توکن، به صورت خودکار رفرش می‌شود
- در صورت خطای 401، کاربر به صفحه لاگین هدایت می‌شود
- تمام درخواست‌ها شامل هدر `Authorization: Bearer <token>` هستند
